# To Do Application

## Description
This is a simple To Do application built with NestJS.

## Getting Started

### Prerequisites
- Node.js (>= 16.x)
- npm (>= 5.x)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/faryalawais/spinostest.git
   cd spinostest
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application
To start the application, run:
```bash
npm run start
```

### Testing
To run tests, use:
```bash
npm run unit
```

### Linting
To lint the code, use:
```bash
npm run lint
```

### Building
To build the application, use:
```bash
npm run build
```
