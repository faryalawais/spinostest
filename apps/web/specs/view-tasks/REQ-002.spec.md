# REQ-002: View Tasks

## Behavior
- User sends a request to the API endpoint to retrieve all tasks.
- Application queries the database for all tasks.
- Application formats the task data including titles and completion status.
- Application sends the formatted task data back to the user.

## Components
- TaskController
- TaskService
- TaskRepository

## Acceptance Criteria
- [ ] AC-001: The API returns a 200 status code when tasks are successfully retrieved.
- [ ] AC-002: The response contains an array of tasks with 'title' and 'completed' fields.
- [ ] AC-003: The response is in JSON format.

## Test Cases
- TC-001: Retrieve all tasks successfully.
- TC-002: Verify the structure of the task data in the response.
- TC-003: Check response format.

## Notes
Ensure that the database is seeded with test data for tasks before running the tests.
